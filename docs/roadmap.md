# Roadmap

Statuses below are honest portfolio labels, not marketing claims.

## Now / active

- Evolve Parts storefront + store cabinet (supplier APIs, pricing, orders/leads)
- Evolve Service discovery + service cabinet (clients, booking posts, appointments)
- Operate shared platform on VPS (Docker Compose, Postgres, Redis, workers)
- Deepen Applied AI ads-ops agent (structure, policy, HITL)
- Expand Flutter companion feature quality and API continuity

## Next

- Stronger evaluation and observability for AI plans (quality, cost, failure modes)
- Tighter Garage ↔ Parts ↔ Service loops in the mobile app
- Safer retries/timeouts standardization across external clients
- Public portfolio: screenshots (test data), richer demos, diagram polish

## Later / exploratory

- RAG over operator knowledge bases — only if a concrete production use case justifies it
- Broader CRM connectors beyond what is already scoped privately
- Push-notification depth (if/when mobile push is production-hardened)
- Multi-agent orchestration — experimental, not a near-term production goal

## Explicitly not claimed

- Autonomous AI that changes ad spend without human apply
- Complete offline-first mobile sync
- Performance SLOs or revenue metrics in this public repo
